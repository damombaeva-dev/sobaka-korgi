# Остатки

Страница `ostatki/index.html` работает сама, без сервера и без чьей-либо помощи:
браузер скачивает Google Таблицу (экспорт в xlsx) каждые 30 секунд и рисует её.

## Что нужно, чтобы всё работало

1. В таблице включён доступ «Все, у кого есть ссылка — Читатель».
2. Вкладки месяцев называются «Месяц ГГГГ», например «Ноябрь 2026», «Август 2027».
   Показываются вкладки с ноября 2026 и позже; скрытые вкладки не показываются.
   Новая вкладка появляется на сайте сама, удалённая исчезает сама.
3. Порядок столбцов как сейчас: A остаток, B клиент, C кол-во, D бронь, E отгрузка
   (дата = отгружено), F условия, G примечание, H менеджер.
4. Строка с текстом только в столбце A — это товар; если сразу под ней ещё одна такая строка —
   первая считается поставщиком.

## Что менять в коде (если понадобится)

- Другая таблица: `DEFAULT_SHEET` в `index.html`.
- С какого месяца показывать вкладки: `START`.
- Цвета поставщиков: `SUP_FIXED`.
