# Спецификации менеджеров

Страница `specs/` — доска подписанных спецификаций Ольги и Анны: канбан по срокам отгрузки, таймлайн по неделям, архив «Отгружено».
Каждая спецификация автоматически ищет свою бронь в Остатках (та же Google Таблица, что и на странице «Остатки»), или привязывается к брони явно при добавлении.

## Спецификации прямо из Excel «Остатки»

Столбцы сразу после «Ответственного» (H):
- **I** — номер недели отгрузки: `49`, `50-51`, `нед 3/2027`. Заполнено = спецификация подписана. Можно вместо недели написать «№12 от 20.11.2026».
- **J**, **K** — необязательно: отгрузка «с» и «по» (дата или неделя), если нужен точнее срок.

Клиент, кг, условия (F), менеджер (H), товар и поставщик берутся из строки брони. Дата в «Отгрузке» (E) — спецификация уходит в «Отгружено». Пометки вроде «НЕ ВЛЕЗАЕТ…» в I спецификацией не считаются.
Бот раз в 5 минут смотрит таблицу и пишет менеджеру о каждой новой такой строке.

## Хранилище и Telegram (Google Apps Script)

Код: `apps-script.gs` (без токена бота; копия с токеном лежит у Аиды в файлах проекта).

1. script.google.com → «Создать проект» → название «Спецификации менеджеров».
2. Стереть всё в `Code.gs`, вставить код целиком. В `BOT_TOKEN` — токен бота, в `PIN` — код для изменений (или оставить пустым).
3. Вверху выбрать функцию `setup` → «Выполнить» → разрешить доступ (Таблицы, Диск, внешние запросы). Создаются таблица «Спецификации менеджеров (сайт)», папка «Спецификации менеджеров (файлы)» и два таймера: опрос бота каждые 5 минут и план по понедельникам в 9:00 МСК.
4. «Развернуть» → «Новое развертывание» → тип «Веб-приложение» → Запуск от имени: «Я», Доступ: «Все» → скопировать URL `…/exec`.
5. URL вставить в `API_URL` в `specs/index.html`.

После правки кода в Apps Script: «Развернуть» → «Управление развертываниями» → карандаш → Версия «Новая» → «Развернуть» (URL не меняется).

## Telegram

На странице раскрыть «Напоминания в Telegram»: у каждого менеджера своя ссылка `t.me/<бот>?start=olga|anna`, у руководителя `?start=all` (копии всего).
Бот пишет при добавлении спецификации, по понедельникам в 9:00 присылает план (просрочено / эта неделя / 2 недели / позже / брони из Остатков без отгрузки). Команды в чате: `/week`, `/stop`.
